Your idea. Editable motion.
No AI account required.

Trolic is a text-based vector animation tool:not an AI image generator. Write a small scene, preview it, and export motion you can inspect and change. You can author by hand or ask an assistant to write the source.

Web & app interfaces

Make lightweight geometric loaders, success states, onboarding illustrations and decorative loops. Export Lottie JSON and test it in your actual web or mobile player.

Brand & social layouts

Reframe original vector art into square, portrait, story or widescreen canvases. Use SVG for a static frame. Video/GIF export is not built in.

Learning & prototyping

See how pivots, easing, timing and hierarchy create motion. Keep source in version control, reuse shapes and reproduce the same export locally.

Simple vector deliveryLottie JSON and SVG from one scene; independent playback checks.Text shaping, masks, arbitrary-topology morphing, video, advanced filters and full SVG import need other tools.

The historical v0.4 eight-scene benchmark measured about 51% fewer source tokens with two named tokenizers. That is not a general speed, quality or cost advantage over other animation tools. v0.9 passes 454 automated checks; new scenes were checked in 21 paired frames against Lottie-web SVG. Always test your delivery player.

Don’t repeat yourself.
Or your tokens.

Keep the readable format when you want it. Switch to agent syntax when context matters. Both go through the same validation and rendering pipeline.

  • 01
    Define once. Reuse everywhere.Styles, constants, and single-node prototypes reduce repeated structure.
  • 02
    Describe patterns, not every instance.Bounded repeats and column-based batches handle regular and irregular detail.
  • 03
    Edit a node, not an entire scene.Stable IDs, atomic edits, revision checks, and concise agent receipts.

Language reference
⌁
Real vector geometry
Cubic and quadratic paths, smooth and relative commands, compound contours, fill rules, gradients, and strokes.
↻
Structured motion
Transform groups and multi-keyframe position, scale, rotation, and opacity. Four easing curves. Deterministic exports.
⌘
Agent-oriented editing
Compact fields, reusable definitions, batches, repeats, selected-field inspection, and atomic revision-checked edits.
◇
Shared compiler core
Dependency-free JavaScript compilation in Node and the browser. Cloud hosts can wrap the same core; no cloud API is included.

What this is:and what it isn’t.
Trolic is an experimental open-source authoring tool, not a production-certified animation engine or a hosted AI generator.
  • No embedded model, cloud API, text shaping, masks, general SVG import, video export, or dotLottie packaging yet.
  • Only the Lottie-web SVG renderer has been exercised here. Check your actual target player before shipping.
  • Spring entrances are sampled keyframes, not a physics solver. Draw-on is limited to unfilled single-contour strokes.
  • Source compression does not reduce expanded layer count or guarantee faster playback.
  • Compiler budgets are safeguards:not a security sandbox. Isolate untrusted workloads.
Do I need an AI account or API key?
No. Compilation and the offline studio work without an AI service. You can use an external assistant to author the language, but Trolic does not call one for you.
Are the token savings universal?
No. They are exact source counts for eight fixtures under two named encodings. Guide and protocol overhead, reasoning and retries are separate. Other tokenizers and scenes can behave differently.
Can I use it commercially?
The original Trolic code and artwork are MIT-licensed. The bundled Lottie-web player retains its upstream license. Review all dependencies and your delivery requirements; no legal or platform-compatibility guarantee is implied.
Is this Frolic source code?
No. Trolic is an independent implementation. Public examples informed broad feature research; the repository contains original Trolic code and artwork, not Frolic source assets or its compiler.
